# Logo assets used in the README result figure

The Qwen, OpenAI, Google, and Meta marks were extracted from the project-maintainer-supplied six-model display that this figure replaces. The Z.ai mark comes from the public `z.ai` favicon SVG, and the Ornith mark is the public avatar shown by the model author's Hugging Face organization. These marks identify model families only; they do not imply endorsement. All numerical geometry is generated independently from `results/tables/s7/S7_T1_model_condition_summary.csv`.
