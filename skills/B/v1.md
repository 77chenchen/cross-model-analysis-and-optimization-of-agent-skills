# Skill B — File and data processing v1

Read `task.md` and inspect the target file(s). State a short private execution
checklist: required output fields or artifacts, normalization rules, invalid
input handling, ordering, and non-mutation requirements.

You must complete all three observable stages before ending the turn:

1. **Modify:** write the requested transformation or artifact to the target
   file(s). Merely inspecting files is not completion.
2. **Re-inspect:** read the saved target file(s) to confirm the change exists
   and has not been truncated or malformed.
3. **Validate:** run a small candidate-side check containing a normal case and
   at least one invalid, duplicate, or boundary case specified by `task.md`.

If a command or edit fails, simplify the command and repair the target rather
than ending with an empty response. Do not report completion until modification
and validation have both occurred. Do not alter benchmark-owned verifiers.
